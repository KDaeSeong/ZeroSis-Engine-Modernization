# 현지화 제공자 x64 이식

2026-09-25 작업 중이랍니다. 현재 GameCore의 현지화 연결 요구 16개와 이를 뒷받침하는 문구 사전·인수 치환·언어별 서식·객체 수명을 구현할 범위로 확정하였사와요. 원본 SDK 공개 계약과 설치된 원본 x86 현지화 DLL의 실행 기록을 기준으로 삼겠사와요.

영향 범위는 독립 프로젝트의 Localization 제공자, 복사한 참조 DLL·ICU 자료, 소유한 시험 DB, 빌드·검증 도구와 검토용 Stage랍니다. 기존 게임·SDK·MODS·저장 자료와 현지화 키는 변경하지 않사와요. 문자열 객체의 SDK 배치와 실제 호출 계약을 유지하며, 사전·문법·서식 기능을 구현하지 않은 채 성공으로 반환하는 연결 처리는 사용하지 않사와요.

먼저 원본의 초기화·사전 조회·폴백·중첩 인수·복수형·성별·한국어·서식·실패 동작을 독립 시험으로 기록하와요. 실제 x64 구현, 원본 비교, 실패·소유권 검증과 실제 GameCore 연결을 마쳐야 이 제공자의 연결 관문을 통과한 것으로 보겠사와요. 전체 실행부·UI·실게임 모드 호환성은 별도 관문이랍니다.

## 현재 구현과 검증

**숫자·문자 변환의 내부 x64 구현을 만들고 숫자 출력 1,162개를 원본과 일치시켰사와요.** 이 문서는 내부 숫자·문자 변환 단계의 기록이랍니다. 후속 SDK 문장·사전 연결에서 요구사항 16개를 해소하여 전체 미연결 항목은 **36개**가 되었사와요. [후속 구현과 검증 범위](M2_LOCALIZATION_INTEGRATION.md)에 상세 근거가 있답니다.

| 요구사항 | 구현·증거 | 현재 판단 |
|---|---|---|
| LOC01 / 원본 언어 자료 | 복사한 `icudt44l.dat`의 원본 SHA-256 대조, 메모리 적재 후 ICU 파일 탐색 차단 | 독립 시험 통과 |
| LOC02 / x64 언어 처리 | 공식 ICU 4.4.2 고정 커밋·보관 ZIP·원본 642파일 검증, 공통 151·국제화 149·데이터 연결용 1 오브젝트 | 301개 AMD64 오브젝트와 정적 라이브러리 3개 생성 |
| LOC03 / 숫자 서식 | 실제 `SdkLocalizationIcu.cpp` 오브젝트를 시험에 연결하고 연결 지도 확인 | 기본 22개 + 경계 자료 1,140개 출력 정확히 일치 |
| LOC04 / 실패 시 출력 보존 | 비정상 규칙 기반 숫자 48건, 잘못된 서식·UTF-8·길이·종류·빈 포인터 검사 | 검사한 실패에서 기존 문자열 보존 |
| LOC05 / Unicode·긴 문자열 | 대소문자 12개, 내장 NUL·한글 서식·보충 평면 문자·16,384자 변환·1,029자 숫자 출력·자기 버퍼 입력 | 독립 시험 통과 |
| LOC06 / 독립 서식 객체 | 호출마다 별도 서식 객체 소유, 작업자 4개의 숫자·문자 변환 2,048회 | 결과 일치; 게임 병렬화·속도 측정과 별개 |
| LOC07 / 문장·사전·SDK 연결 | 원본의 기본·인수·서식·형태·사전·숫자 자료 6개 실행 모드 기록 | x64 `String`·사전·문장 해석기 구현 대기 |

숫자 자료는 영어·한국어, 서식 11종, int·int64·float·double 54개 입력 조합이랍니다. 규칙 기반 서식의 비정상 값 48조합은 정상 출력 비교에서 제외하고 x64의 명시적인 거부 시험으로 분리했사와요. 나머지 1,140조합에는 64비트 최소·최대 정수, 2^53 경계, 음수·음의 0·작은 소수·큰 값·일반 서식의 NaN·무한대가 포함되어 있답니다. 원본 일반 서식은 무한대를 `NaN`으로 표시하므로 관찰된 결과를 보존했사와요.

내부 API는 ICU 초기화와 언어 자료의 수명이 유효한 동안 호출하는 계약이랍니다. 초기화·종료를 SDK에 연결하는 수명 관리, 전체 메모리 부족 주입, 문법·사전·폼·성별·복수형 선택과 실제 게임 호출부는 아직 검증 전이와요.

## 원본 결함과 제약

- 원본 DLL의 `spellout(float quiet NaN)`은 별도 프로세스에서 **0xC00000FD / 스택 소진**으로 종료되와요. 새 내부 구현은 로마 숫자·영문 읽기·서수의 NaN·무한대를 ICU 호출 전에 거부하고 기존 출력을 보존하와요. 원본 충돌 대신 적용한 명시적인 결함 수정이랍니다.
- ICU44의 최소 int64 규칙 기반 서식에는 0 크기 사전 조회와 다음 호출 사이에 필요한 길이가 달라지는 사례가 있었사와요. 실제 버퍼로 먼저 변환하고 크기 부족 시 반환된 길이로 제한된 재시도를 수행하와요. 최소 정수의 원본 출력과 긴 서식 출력을 다시 확인했답니다.
- 설치된 언어 자료의 제목형 변환은 필요한 리소스가 부족하여 6개 시험에서 `U_MISSING_RESOURCE_ERROR`를 반환하와요. 원본 `{1_Name:title}`도 빈 결과를 반환했답니다. 새 내부 API는 실패를 명시하고 기존 출력을 보존하며, SDK 문장에 반영하는 규칙은 다음 단계에 연결하와요.
- 직접 작성한 내부 구현과 시험 프로그램은 `/W4 /WX`에서 경고 없이 빌드되었사와요. **외부 ICU 원본의 경고 발생 77건**은 기록에 남겼답니다. 숫자 폭·구식 API·선언·최신 컴파일러 진단이 포함되며, 기존 GameCore의 경고 343개 위치와는 다른 집계이와요.

2026-09-25에는 SDK `SharedString` 저장·복사와 매개변수 저장을 x64 부품으로 구현했사와요. 원본 저장 동작 50줄과 일치하고 작업자 4개의 독립 복사본 4,096개를 확인했답니다. 원본 문법·형태·대입의 4개 추가 모드는 다음 해석기 구현의 기준 기록이며 아직 x64 문장 합성의 통과 결과는 아니와요. [정확한 범위와 다음 조건](M2_LOCALIZATION_VALUES.md)
