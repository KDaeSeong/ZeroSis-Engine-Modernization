# 원본 지형·물 후속 12단계 — 2·3번

기준일: 2026-11-16. 실게임·화면 확인 보류를 유지한다. Claude의 곡면 기저·실제 세계 카메라·숲 담당 파일은 변경하지 않았다.

## 이번 변경

| 범위 | 생산 코드 변경 | 아직 연결하지 않은 부분 |
|---|---|---|

기존 높이 폭 `2.3`은 확인된 기본 metric으로 교체했다. 64원본 단위로 정규화한 u16 전체 높이 폭은 약 `0.80312502384`다. `15300`은 현재 표시 원점의 후보로만 유지하며 원본 수위로 확정하지 않는다. 조각 stamp의 reference 인자와 표시 원점의 의미도 구분한다. 논리 육각 격자·선택의 `.866025404`와 재질/원본 법선의 `.866f`는 서로 다른 변환 단계다.

## 독립 계산 부품

`OriginalTerrainCacheSamplingModel.h`는 원본 scratch의 128/256/512 크기, half-texel 보정, 소스/샘플 UV 관계와 높이 정규화·절삭을 별도 API로 제공한다. 현재 68/66 halo 필드가 원본 공유 scratch와 같은 기하라고 주장하지 않는다. 비정사각 chunk의 upper-Y와 UV-Y 필드 차이는 별도 미확정이며 현재 64×64 입력에는 영향을 주지 않는다.

`OriginalReflectionProjectionModel.h`는 명시적으로 제공된 원본 bounds/axis에서 RH view·orthographic projection과 물의 UV를 계산한다. `supplied=false`가 기본이며, 실제 원본 입력을 확보하지 않은 생산 경로에서 자동 활성화하지 않는다. 생산 Raw의 현재 mirror camera는 후보이고, 이번 변경은 그 후보를 그리기와 소비 양쪽에서 일관되게 사용하는 연결 수정이다. 지형 최종 t9는 정적 specscreenmap DDS이고 물의 Raw와 별개다.

`OriginalIceContract.h`, `OriginalIceAssets.h`, `OriginalIceShader.h`는 원본 8바이트 정점·16비트 색인·20바이트 cull bounds, 8비트 LEAN/BC3/BC1/L8 판독 및 정점 셰이더 부품이다. 원본 얼음은 균열·fracture 절차 지형을 요구한다. 전체 픽셀 셰이더·균열 생성·제출을 구현하지 않았으므로 geometry/material provider는 false다. 단순 육각 얼음을 대체 제출하지 않는다. scalar LEAN은 파일상 1바이트/텍셀이며 원본 loader format 0x41 및 PS alpha 채널을 물의 R16/R8 SRV와 혼동하지 않는다. FPK/loose high/low XML의 차이는 기록했지만 실제 검색 우선순위는 미확정이다.

기존 6개 자산 팩은 그대로 재사용하고 새 자산 팩을 만들지 않았다. 원본 설치·MODS·설정·사용자 저장·기본 실행·전역 등록·저장 ABI는 변경하지 않는다. 최신 기존 격리 실행 묶음은 11단계 `20261116T123457Z_90b98a574efc`이며 이번 소스 변경과 동일한 실행 묶음으로 표시하지 않는다. Host, SDK DLL, CLR, HWND, GPU, 음향 및 실제 게임은 실행/로드하지 않는다.
