# ZeroSis' 얼리 액세스 0.6

2026-10-12 기준, 문명 5의 실제 게임 로직을 64비트로 실행하는 **로컬 초기 플레이용 프로토타입**이와요. 이번 버전은 생산 선택창을 다시 열 때 원본 진행 표시와 화면 상태를 보존하도록 수정했답니다. 기존의 첫 화면 자동 유닛 선택·원본 유닛 패널·도시 구매 후 복귀도 포함하와요.

새 게임 자동 검증에서 **6턴 진행·저장 2회·정상 종료**를 확인했사와요. 별도 프로세스에서 그 저장을 복원해 **12턴까지 진행·재저장·정상 종료·의미 상태 일치**도 확인했답니다. 원래 복원 검사 결과는 알림 순서를 잘못 기대한 검증기 때문에 실패로 남아 있으며, 보존된 원본 기록에 대한 별도 검증 통과를 함께 기록했사와요. 이 결과가 일반 플레이 한 판 완주나 원본 전체 UI·기존 저장 호환성을 뜻하지는 않사와요.

일반 실행기의 **새 게임 시작·F5 저장·별도 프로세스 불러오기·정상 종료**도 확인했사와요. 이번 확인은 0턴에서 자동 입력으로 수행했고, 복원 전후 SDK 상태 표본이 일치했답니다. 직접 플레이한 한 판의 안정성은 아직 확인하지 않았사와요.

## 시작하기

프로젝트의 `Play/EarlyAccess` 폴더에서 원하는 실행기를 여시와요.

| 실행기 | 동작 |
|---|---|
| [새 게임.cmd](../Play/EarlyAccess/새%20게임.cmd) | 현재 EA의 새 게임 시작 |
| [이어하기.cmd](../Play/EarlyAccess/이어하기.cmd) | 보관된 EA 버전에서 마지막으로 직접 저장한 게임 열기. 직접 저장한 게임이 없으면 새 게임 시작 |
| [불러오기.cmd](../Play/EarlyAccess/불러오기.cmd) | `.zssave` 파일을 직접 선택. 보관된 이전 실행본의 저장도 해당 버전으로 열기 |

**이번 화면 변경을 보려면 위 폴더의 `새 게임.cmd`로 시작하시와요.** `이어하기`와 `불러오기`는 저장을 만든 버전으로 연결되므로 이전 저장에는 0.6의 화면 변경이 적용되지 않사와요.

새 게임은 **미국·워싱턴 / 상대 로마 / 대륙 / 결투 크기 / 왕자 / 보통 속도 / 고대 시작**의 고정 구성이랍니다. 지도 생성값도 고정이며, 문명·지도 설정을 자유롭게 고르는 시작 화면은 아직 없사와요. 게임 창이 열린 뒤 직접 조작하는 방식이랍니다.

## 지도에서 조작하기

| 조작 | 동작 |
|---|---|
| 유닛 왼쪽 클릭 | 내 유닛 선택 |
| 이동할 칸 오른쪽 클릭 | 선택한 유닛 이동. 공개된 칸과 실제 이동 가능 조건 적용 |
| 내 도시 왼쪽 클릭 | 도시 화면 열기 |
| `Tab` | 명령을 기다리는 다음 유닛 선택 |
| `Space` | 선택한 유닛의 이번 턴 건너뛰기 |
| `Enter` 또는 오른쪽 아래 원본 턴 안내 버튼 | 안내 상태에 따라 유닛 선택·생산/연구 선택창 열기. 필수 선택과 유닛 행동을 마치면 다음 턴 진행 |
| 방향키 | 지도 이동 |
| `F5` 또는 화면의 저장 | 현재 게임 저장 |
| `Esc` 또는 상단 메뉴 | 지도에서 원본 게임 메뉴 열기. 메뉴에서 `Esc` 또는 게임으로 돌아가기: 복귀 |
| 오른쪽 닫기 또는 창의 × | 안정된 턴에서 저장 후 종료 |

첫 화면에서는 행동할 수 있는 유닛 하나가 자동 선택되며, 왼쪽 아래 원본 유닛 패널이 나타나와요. 개척자의 원본 행동 버튼으로 **도시 건설 → 연구·생산 선택 → 남은 유닛 행동 → 턴 종료 → 저장** 순서로 진행하시와요. 연구·생산 선택 버튼과 도시 화면을 이용할 수 있고, 상단 과학 표시에서 연구 화면, 금 표시에서 경제 화면을 열 수 있답니다.

게임 메뉴에서는 **빠른 저장과 게임으로 돌아가기**를 이용할 수 있사와요. 일반 저장·불러오기·설정·재시작·포기·나가기의 하위 동작은 아직 미지원 안내로 연결되므로, 저장은 `F5`·오른쪽 저장·메뉴의 빠른 저장을, 종료는 오른쪽 닫기나 창의 ×를 이용하시와요. 상단 왼쪽의 과학·금 등 정보는 첫 도시를 세운 뒤 표시되는 원본 동작이랍니다.

턴 안내 버튼의 **명령이 필요한 유닛·생산 선택·연구 선택·다음 턴** 문구를 확인하시와요. 선택창 안에서는 그 창의 원본 조작이 우선하므로, 저장·종료는 선택을 마치고 지도 화면으로 돌아온 뒤 하시와요. **저장 완료 문구를 확인한 뒤 종료**하시와요. `.zssave`는 이번 엔진 전용 저장 파일이랍니다. 시작 시 만드는 자동 저장은 `불러오기`로 선택할 수 있고, `이어하기`는 `F5` 또는 저장 버튼으로 직접 만든 저장을 찾는답니다.

## 지금 남아 있는 제한

- 일꾼 추천 행동 문구 일부에 원본 링크 표시 코드가 남아 있사와요.

- 전사 모델과 대기 동작을 연결했으나, 다른 유닛·도시·시설 모델과 이동·전투 애니메이션·지형 효과는 미완성이랍니다. 지도와 오른쪽 패널도 아직 임시 표시를 포함하와요.
- 원본 게임 메뉴의 하위 화면, 문명 백과사전·종교·관광 등에는 아직 미연결 경로가 있사와요.
- 원본 알림 목록을 포함했으나 모든 알림 종류의 연결, 툴팁 표시·시작 시 선택 외의 자동 유닛 순환·UI 애니메이션의 원본 동등성은 아직 남아 있사와요.
- 이전 버전 저장은 그 저장을 만든 실행본으로 열리와요. 화면 변경과 이후 버전의 종료 수정은 이전 저장에 소급 적용되지 않으며, 0.2에서 관측된 종료 오류가 남아 있을 수 있답니다.
- 전체 캠페인 완주, 원본 UI 전체 동등성, 모드 호환, 기존 문명 5 저장 불러오기, 멀티플레이는 검증하지 않았사와요. 높은 FPS나 원본보다 빠른 전체 게임 속도도 보장하지 않사와요.

문제가 생기면 **마지막으로 한 조작, 오류 문구, 관련 `.zssave` 파일**을 남겨 주시와요. 짧은 업데이트에서는 실제 플레이를 막는 문제부터 다루고, 바뀐 점과 확인한 범위를 함께 안내하겠답니다. 중간 빌드·실패 검사·중복 자료는 정리하되 **사용자 저장과 그 저장을 여는 데 필요한 실행본은 보존**하와요.

이전 개발·검증 기록은 [연속 게임 실행 경로](CONTINUOUS_PLAY.md)에 남아 있사와요.
