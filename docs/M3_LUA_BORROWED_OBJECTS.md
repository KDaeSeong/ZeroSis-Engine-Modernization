통합 전 별도 후보 DLL 연결에서는 attempt_036의 제공자 라이브러리 16개를 재사용했사와요. 당시 내보내기 3개와 DLL 안의 공유 수명 레지스트리 심볼 1개를 확인했으며, 이력 DLL 해시는 `660e1280fed35044aa4b13d9a969c0ddaf6597c4878cfa014479ffcc52f3a584`이랍니다. 이 기록은 현재 정식 연결·Stage·실행 검증을 대신하지 않사와요. 현재 구성요소 검증은 `production_verification.json`으로 추적하며 `candidate_verification.json`은 통합 전 이력이랍니다.

전체 SDK 후보의 경고는 경로 중복을 정규화하면 기존과 같은 343곳(C4819 325곳·C4091 5곳·C4996 13곳)이랍니다. CvPlayer의 기존 C4996 세 위치는 삽입된 코드 때문에 행 번호만 4줄 이동했사와요. 위의 경고 0건은 분리된 구성요소 시험 프로그램 4종에 해당하와요.

현재 읽을 수 있는 ModBuddy·설치 MODS Lua 파일에서 `__instance`/`__instances` 직접 사용은 발견하지 못했사와요. Build·Civ5 Source·outputs·Python 패키지를 제외한 텍스트 검색이며, 숨김/무시 파일이나 동적 키 구성·실행 호환성을 증명하지 않사와요. 명령·범위·오류 0건 기록은 `lua_pointer_field_scan.json`에 있답니다.
