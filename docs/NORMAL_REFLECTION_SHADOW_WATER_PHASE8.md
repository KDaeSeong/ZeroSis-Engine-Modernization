# 원본 법선·반사·동적 그림자·물 안개 8단계

2026-11-15. 사용자 요청 2–5의 실게임 없이 가능한 구현 범위다. 서브에이전트 3개가 원본 명령 추적·화면 반사·물 안개를 분담하고, Root가 동적 그림자와 통합을 구현했다. 동적 그림자도 별도로 서브에이전트가 검토했다.

Host/GameCore/CLR/HWND/GPU/음향 장치/실게임/화면 도구 실행은 보류다. 원본 설치·MODS·원본 설정·사용자 저장·기본 실행·전역 등록과 SDK ABI/저장 스키마는 바꾸지 않았다. 실제 C++ 컴파일·링크와 순수 CPU/셰이더 컴파일만 허용한다. 전체 엔진 목표가 완료됐다는 뜻은 아니다.

## 2. 기본 정점 법선과 캐시 표현

원본 기본 법선의 bulk 5×5 식, 16개 비영 계수와 합산 순서, 영 계수 행에서도 진행하는 기준값, scalar 대체 경로, 압축 XY 복원과 HALF4 입력을 분리했다. 독립적인 원본 SIMD 명령 식 그래프로 float32 미분을 대조했다. 양수인 평면 높이에서도 원본 bulk 식의 작은 기울기가 남는다. 이를 임의로 평평하게 보정하지 않는다.

재질 투영과 상위8 재질 선택은 원본 float 법선을 쓰고, GPU CacheBake 기본 법선 입력만 half 값으로 양자화한다. 현재 44바이트 정점의 해당 float 필드에는 half에서 복원한 값을 넣는다. 원본 24바이트 정점 메모리 형식을 그대로 사용한다고 주장하지 않는다. Atlas에는 원래 높이 기준 offset만 추가로 보관하며 저장 파일에 쓰지 않는다. float Atlas→uint16 반올림, 현재 세계 단위 배율, 좌표/wrap, double 길이 정규화와 원본 D3DX 정규화 분기는 여전히 보정 후보다. 알려지지 않은 수치 높이는 읽지 않고 알려진 중심값으로 대체한다.

원본 materialH 임시 목표의 RGBA16_FLOAT 중 사용되는 red와 현재 R16_FLOAT의 채널 정밀도가 대응한다. NormalTemp는 RGBA8 typeless 및 UNORM/sRGB 보기 생성으로 확인돼 현재 법선 목표도 RGBA8_UNORM으로 바꿨다. 청크 법선+높이 그림자 논리 텍셀은 43,560바이트에서 26,136바이트로 줄었다. 실제 GPU 할당 측정이 아니다. 원본의 실제 보기 선택, 128/256/512 분기, 전체 밉 갱신·압축·재표본·상주 순서는 미확정이다. 현재 공유H68/청크N66/그림자66/mip0 경로는 이와 분리한 후보로 유지한다.

## 3. 최종 화면 반사와 원본 설정 규칙

최종 t9는 Reflection Texture Raw다. global da12c0→초기화 배열의 +1c→소유자 +564→최종 t9 연결을 고정했다. 이름이 비슷한 specscreenmap.dds는 다른 자원이며 새 팩을 만들지 않았다.

지형 세부 수준3에서 반사를 켜는 초기 규칙, 확산 초기 켜짐, 디버그 두 토글→CB28/27 경로를 renderer-local Policy로 연결했다. 기존 INI와 메뉴 저장 스키마는 읽거나 바꾸지 않으며 이번 정책은 새 메뉴에 노출한 옵션을 뜻하지 않는다. ReflectionLevel1은1024²,0은32² 영 버퍼에 대응한다. 꺼진 경우 장면 재생성을 건너뛰고 영 입력을 쓴다. 원본 비테셀 정점의 clip.xy/clip.w→최종 .5*좌표+.5는 현재 픽셀 (x/폭,1-y/높이)와 같다.

물 반사가 있으면 같은 영상과 깊이를 공유하고, 물이 없고 지형 반사만 필요하면 반사 색/깊이 두 장만 만든다. 전체 화면 굴절 복사는 추가하지 않는다. 반사 장면 안의 지형에는 반사 SRV를 다시 넣지 않아 재귀를 막는다. 메인 t44/b6/s5, 45개 SRV 해제·보존·복원을 연결했다.

원본 소비 수식에는 t9의 추가 감마 변환이 없다. 현재 격리 버퍼는 encoded UNORM이므로 명시적인 생산자 보정으로 decode한 뒤 원본 소비 식에 넣는다. 원본 반사 카메라·수면·실제 보기 색 공간·샘플러는 여전히 후보이며, 현재 지형/유닛 두 부류는 원본 나무/건물까지 포함한 네 장면 부류를 재현하지 않는다.

## 4. 동적 장면 그림자

private 2048² R32 typeless 깊이 한 장으로 알려진 지형과 현재 보이는 유닛 자세를 그린다. 이미 필터링·업로드한 유닛 버퍼를 재사용하고 SDK/RNG/애니메이션 시계를 다시 진행하지 않는다. 실제 물 표면이 있을 때만 생성하고, 소비자가 없으면 해제한다. 메인 색·깊이·정수 ID 목표에 그림자를 쓰지 않는다.

물 t11/b5에서 투영 깊이를 비교해 원본 식 1−.67×그림자×강도에 연결했다. 원본 t13의 수치 소비 식과 현재 깊이 생산자 정책은 구분한다. 광원 카메라·2048 해상도·bias·4탭 필터와 불투명 유닛 실루엣은 미검증 후보다. 논리 깊이 텍셀16MiB는 실제 VRAM 측정이 아니다.

## 5. 물 전용 전장의 안개와 혼합 경계

원본의 감마 출력→premultiplied overlay→회색.4와 R 혼합→R×(1−B) 색표→거리 안개 순서를 색 전용 후처리에 연결했다. 처리 중 입력 장면 알파는 보존한다. R8_UINT Target4 표식은 실제 물 조각만1, 앞에 그려진 유닛은0이며 해안·강 색 오버레이는 기존 표식을 유지한다. 물 타일 전체를 물 픽셀로 간주하지 않는다. 미탐색은 수치 색/색표 접근 전에 차단하고, 후처리는 타일 선택 ID를 쓰지 않는다.

원본 하드웨어 혼합 상태는 새로 확정되지 않았다. 현재 물은 기존 격리 장면과 합성해 alpha1을 내는 후보이며, 후처리 입력 알파 보존이 원본 하드웨어 알파 혼합 복원 완료를 뜻하지 않는다.
