최신 UI 시험판 EA 0.6: Play\EarlyAccess\새 게임.cmd
생산 선택창 재열기 시 원본 진행 표시·화면 상태 보존. 첫 화면 유닛 선택·원본 유닛 패널·도시 구매 복귀 포함.
새 게임 6턴·저장·종료 통과. 보존된 별도 복원 기록은 12턴까지 진행·재저장·종료를 독립 검증. 일반 플레이 완주·원본 전체 UI는 미검증.
일반 실행 0턴에서 F5 저장·별도 불러오기·정상 종료 및 SDK 상태 표본 일치 확인.
이전 저장을 이어 하면 그 저장을 만든 버전으로 열림. 이번 화면 변경은 위 새 게임 실행기에서 확인.
상세 조작과 현재 제한: docs\EARLY_ACCESS_KR.md

엔진 실행.cmd: 마지막 수동 저장 이어서 하기. 저장이 없으면 최신 버전의 새 게임 시작.
새 게임.cmd: 이전 기본 개발판의 새 지도에서 시작. 최신 UI 시험판은 위 EA 0.6 실행기 사용.
저장 불러오기.cmd: .zssave 파일 선택. 저장에 맞는 보관 엔진 버전으로 열기.

조작
- 유닛 왼쪽 클릭으로 선택한 뒤 목적지 타일 오른쪽 클릭: 이동
- 도시 클릭: 원본 도시 화면 열기. 시민 집중·성장 회피·전문가 수동 배치·작업 타일 선택
- 도시 화면 → 생산 선택: 생산 지정 후 같은 도시 화면으로 복귀
- 도시 화면 → 타일 구매 → 금액이 표시된 타일: 원본 가격으로 구매
- 도시 화면 → 구매: 가능한 유닛·건물 금 구매
- 연구 선택 → 연구 목록 또는 연구 트리: 연구 지정
- 연구 완료 팝업 → 계속: 닫고 게임으로 복귀
- 개척자 선택 → 도시 건설: 도시 건설
- 유닛 선택 → 왼쪽 아래 원본 유닛 패널의 행동 버튼: 현재 가능한 방어 태세·회복·경계·시설 건설 등
- 일꾼 선택 → 시설 건설: 원본 규칙에 따라 턴을 보내며 완성
- Tab: 다음 유닛 / Space: 이번 턴 대기
- Enter 또는 턴 종료: 다음 턴
- 방향키 또는 지도 이동 버튼: 지도 이동
- F5 또는 저장: 저장
- 연구 트리에서 Escape: 트리 닫기
- 세계 화면의 닫기 또는 창 닫기: 안정된 턴에서 저장 후 종료

실행 시간 제한과 자동 조작은 없음.
한 번에 하나의 플레이 창만 실행.
저장은 Build\InteractiveGameRuntime 아래 각 실행 버전의 sessions 폴더에 보관.
이전 저장은 이전 엔진으로 이어지며, 최신 기능으로 시작하려면 Play\EarlyAccess\새 게임.cmd 사용.

현재는 첫 3D 지형 후보의 개발 빌드이며, 완성된 문명 5 대체 실행 파일이 아님.
유닛·도시·시설 등 원본 모델과 물·강·지형 효과, 전체 전투·외교·도시 UI와 음향, 기존 모드와 원본 .Civ5Save 지원은 미완료.
